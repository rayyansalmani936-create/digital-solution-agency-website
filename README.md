# Digital Solution Agency

A responsive, multi-page agency website built around the services you shared: web development, AI automation, design, SEO, and app development. The visual direction uses a dark digital studio aesthetic with acid-lime and lilac accents.

The layout includes mobile navigation, narrow-screen spacing, larger touch targets, and form controls sized for comfortable phone use.

## Pages

- `index.html` — animated home page, services overview, pinned process story, concept work
- `services.html` — individual sections for all five services
- `work.html` — three clearly labeled concept explorations
- `about.html` — studio introduction and working principles
- `contact.html` — project enquiry form that opens a prefilled email draft

## Run it

Open `index.html` in a browser. No build step or JavaScript package is required. Google Fonts load when online; the site has system font fallbacks.

## Before publishing

- Replace the three concept projects on the Work page with real work when ready.
- Update the agency details if you want a different logo or brand colors.

The contact form builds a `mailto:` draft to the supplied agency email in the visitor's email app. The WhatsApp link uses the supplied number. The form does not store or transmit submissions from the website.
